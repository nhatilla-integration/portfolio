Site pessoal de apresentação profissional: experiência, projetos e stack técnica.

## Como executar

```bash
npm install
npm run dev
```

O projeto será iniciado em http://localhost:5173

## Conteúdo

Todo o conteúdo (experiência, projetos, skills, contato) fica centralizado em `src/data/perfil.js`, o que facilita manter o site atualizado sem mexer nos componentes.
